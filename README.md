# EzEng — английский для ПК

Настольное приложение для изучения английского с нуля, вдохновлённое подходом Simpler: короткие уроки, правила простым языком, сборка предложений из слов и интервальное повторение.

## Скачать

Готовая сборка для Windows лежит в разделе [Releases](https://github.com/levkastergit/ezeng/releases):

- `EzEng-Setup-<версия>.exe` — установщик (создаёт ярлыки, можно выбрать папку);
- `EzEng-<версия>-portable.exe` — портативная версия, запускается без установки.

Приложение не подписано сертификатом, поэтому Windows SmartScreen при первом запуске покажет предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае».

**Обновление.** Установленная версия проверяет новые релизы при запуске и показывает баннер на главном экране; вручную — Настройки → Обновления → «Проверить обновления». Установщик скачивается с GitHub, приложение перезапускается, прогресс обучения сохраняется. Портативная версия не обновляется автоматически: скачайте новый файл со страницы релизов.

## Что внутри

- **24 урока в 6 модулях** (A0 → A1): приветствие и to be, семья и have/has, Present Simple, город и предлоги, Present Continuous, прошедшее и будущее время.
- **Каждый урок**: новые слова с транскрипцией и озвучкой → правило простым языком → тренировка.
- **Типы заданий**: выбор перевода, сборка предложения из плиток, перевод на слух, ввод слова, соединение пар, заполнение пропуска. Ошибки возвращаются в конце урока.
- **Повторение слов** по интервальному алгоритму (упрощённый SM‑2): слова приходят на повтор тогда, когда их легко забыть.
- **Словарь** с поиском, **профиль** со статистикой, цель на день и серия дней.
- **Озвучка** всех слов и предложений встроена в приложение и работает офлайн. Клипы сгенерированы нейросетевым голосом [Kokoro TTS](https://github.com/hexgrad/kokoro) (американский английский, голос af_heart, лицензия Apache 2.0); системные голоса Windows используются только как запасной вариант.
- Клавиатура: `Enter` — проверить/дальше, `1–4` — выбрать вариант, `Backspace` — убрать последнюю плитку.

Прогресс хранится локально на компьютере.

## Разработка

```bash
npm install
npm run dev        # dev-сервер Vite (для отладки интерфейса в браузере)
npm run build      # проверка типов + сборка renderer в dist/
npm start          # сборка + запуск Electron
npm run icon       # пересобрать build/icon.png и build/icon.ico
npm run dist       # собрать установщик и portable в release/
```

Для запуска Electron с dev-сервером: запустите `npm run dev`, затем в другом терминале `VITE_DEV_SERVER_URL=http://localhost:5173 npx electron .`.

### Перегенерация озвучки

После правки текстов уроков клипы нужно создать заново:

```bash
python scripts/extract-audio-texts.py items.json      # список текстов + src/data/audio-manifest.json
pip install kokoro-onnx soundfile                       # движок (модель kokoro-v1.0.onnx и voices-v1.0.bin
                                                        # скачать из релизов thewh1teagle/kokoro-onnx)
python scripts/gen-audio-kokoro.py kokoro-v1.0.onnx voices-v1.0.bin items.json wav af_heart 0.9
for f in wav/*.wav; do ffmpeg -i "$f" -b:a 64k -ac 1 "public/audio/$(basename "${f%.wav}").mp3"; done
```

`scripts/gen-audio.ps1` — запасной вариант на встроенном голосе Windows (Microsoft Zira), без нейросети.
