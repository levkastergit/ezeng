# EzEng — английский для ПК

Настольное приложение для изучения английского с нуля, вдохновлённое подходом Simpler: короткие уроки, правила простым языком, сборка предложений из слов и интервальное повторение.

## Скачать

Готовая сборка для Windows лежит в разделе [Releases](https://github.com/levkastergit/ezeng/releases):

- `EzEng-Setup-<версия>.exe` — установщик (создаёт ярлыки, можно выбрать папку);
- `EzEng-<версия>-portable.exe` — портативная версия, запускается без установки.

Приложение не подписано сертификатом, поэтому Windows SmartScreen при первом запуске покажет предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае».

**Обновление.** Установленная версия (EzEng-Setup) проверяет новые релизы при запуске и показывает баннер на главном экране; вручную — Настройки → Обновления → «Проверить обновления». Установщик скачивается с GitHub, приложение перезапускается, прогресс обучения сохраняется. Портативная версия обновляться сама не умеет: она тоже проверяет GitHub и, если вышла новая версия, предлагает открыть страницу загрузки. Скачайте новый файл и запускайте его вместо старого, прогресс хранится отдельно (в `%APPDATA%\EzEng`) и не теряется.

## Что внутри

- **Основной курс: 36 уроков в 6 модулях** (A0 → A1): приветствие и to be, семья и have/has, Present Simple, город и предлоги, Present Continuous, прошедшее и будущее время. В каждом модуле кроме обычных уроков есть урок‑диалог и урок‑текст.
- **Тематические модули** (открыты сразу, 11 штук): слова из поп‑песен, Dota 2, Counter‑Strike 2, Warcraft III, World of Warcraft, союзы и предлоги, разговорный сленг, Path of Exile 2, Core Keeper, Peak, Diablo — по 4–6 уроков с лексикой, фразами и чат‑сокращениями. Всего в курсе 17 модулей, 95 уроков и 858 слов.
- **Три вида уроков**: обычный (слова → правило → тренировка), диалог (реплики двух героев с озвучкой, затем задания по репликам) и текст (короткий рассказ с переводом, вопросы на понимание, задания по предложениям). Задания: выбор перевода, выбор на слух, сборка предложения, перевод на слух, ввод слова, пары, пропуск, «верно/неверно», вопросы по тексту.
- **Бесконечный режим ∞** у каждого модуля: случайные задания по всем словам и фразам модуля порциями по 12, счётчик серии и XP за каждую порцию.
- **Аккаунты**: вход по логину и паролю, прогресс и достижения хранятся на сервере проекта и подтягиваются на любом компьютере; можно заниматься и без аккаунта (прогресс тогда только локальный). Таблица лидеров по XP в профиле (можно скрыть себя в настройках). Экспорт и импорт прогресса в файл.
- **Достижения и уровни**: 52 достижения в шести группах (уроки, слова, серии, опыт, режимы, особые), 10 уровней по XP от «Новичка» до «Легенды», всплывающие уведомления при открытии.
- **Задания дня и слово дня** на главном экране: три задания, которые меняются каждый день, бонус +25 XP за выполнение всех; слово дня с картинкой, транскрипцией и примером.
- **Картинка к каждому слову** — иллюстрации [Twemoji](https://github.com/jdecked/twemoji) (CC BY 4.0), подобраны вручную для всех слов курса.
- **Транскрипция русскими буквами** рядом с IPA у каждого слова (hello — хэло́у): в словаре, на карточках и в заданиях. Генерируется из IPA скриптом `scripts/add-cyrillic-words.py`.
- **Звуки и алфавит**: 26 букв с названиями и озвучкой, 25 ключевых звуков с подсказками по артикуляции и примерами.
- **Скороговорки**: 20 классических скороговорок с транскрипцией, переводом, обычным и медленным темпом.
- **Песни**: 12 известных песен, тексты которых в общественном достоянии (Amazing Grace, Jingle Bells, Scarborough Fair…), с построчным переводом, транскрипцией и озвучкой каждой строки; свои песни можно добавить вручную (текст + перевод).
- **Сказки**: 8 классических сказок (Три поросёнка, Златовласка, Красная Шапочка, басни Эзопа, Гадкий утёнок, Джек и бобовый стебель), пересказанные простым английским, с переводом, озвучкой абзацев и иллюстрациями из старинных изданий (общественное достояние, Wikimedia Commons; авторы указаны под картинками).
- **Тест уровня**: адаптивный тест из трёх частей (словарь A1–C1, грамматика A1–B2, чтение A1–B2), каждый раз с новым набором заданий; результат по шкале CEFR с историей попыток. Точность примерно до одного уровня, это ориентир, а не сертификат.
- **Модули «Союзы, предлоги и слова-связки» и «Разговорный сленг»**: but/because/between/through/always и cool/dude/no way/lol/no cap, с правилами употребления.
- **Турбо-режим** (кнопка ⚡ в уроке или в настройках): ответ проверяется сразу при выборе, верный ответ автоматически ведёт дальше. **Пропустить** есть в каждом задании. **Режим без звука** в настройках заменяет задания на слух обычными. Незаконченный урок сохраняется и продолжается с того же места.
- **Повторение слов** по интервальному алгоритму (упрощённый SM‑2): слова приходят на повтор тогда, когда их легко забыть.
- **Словарь** с поиском, **профиль** со статистикой, цель на день и серия дней.
- **Озвучка** всех слов и предложений встроена в приложение и работает офлайн. Клипы сгенерированы нейросетевым голосом [Kokoro TTS](https://github.com/hexgrad/kokoro) (американский английский, голос af_heart, лицензия Apache 2.0); системные голоса Windows используются только как запасной вариант.
- Клавиатура: `Enter` — проверить/дальше, `1–4` — выбрать вариант, `Backspace` — убрать последнюю плитку.

Прогресс хранится на компьютере (`%APPDATA%\EzEng`, отдельно для гостя и для каждого аккаунта) и, если вы вошли в аккаунт, на сервере проекта. На сервере лежат логин, хэш пароля (scrypt) и JSON с прогрессом; при входе на новом компьютере берётся более свежая из двух копий. Если сервер недоступен, приложение работает офлайн и отправит прогресс позже.

## Разработка

```bash
npm install
npm run dev        # dev-сервер Vite (для отладки интерфейса в браузере)
npm run build      # проверка типов + сборка renderer в dist/
npm start          # сборка + запуск Electron
npm run icon       # пересобрать build/icon.png и build/icon.ico
npm run dist       # собрать установщик и portable в release/
```

Для запуска Electron с dev-сервером: запустите `npm run dev`, затем в другом терминале `VITE_DEV_SERVER_URL=http://localhost:5173 npx electron .`.

### Перегенерация озвучки

После правки текстов уроков клипы нужно создать заново:

```bash
python scripts/extract-audio-texts.py items.json      # список текстов + src/data/audio-manifest.json
pip install kokoro-onnx soundfile                       # движок (модель kokoro-v1.0.onnx и voices-v1.0.bin
                                                        # скачать из релизов thewh1teagle/kokoro-onnx)
python scripts/gen-audio-kokoro.py kokoro-v1.0.onnx voices-v1.0.bin items.json wav af_heart 0.9
for f in wav/*.wav; do ffmpeg -i "$f" -b:a 64k -ac 1 "public/audio/$(basename "${f%.wav}").mp3"; done
```

`scripts/gen-audio.ps1` — запасной вариант на встроенном голосе Windows (Microsoft Zira), без нейросети.

Скрипты читают `src/data/m*.ts` и `src/data/extra/*.ts` (дополнительные уроки модулей). После добавления слов: `python scripts/add-cyrillic-words.py` (транскрипция кириллицей из IPA) и `python scripts/fetch-images.py` (иллюстрации по эмодзи в поле `img`).

### Сервер аккаунтов

`server/server.js` — API без зависимостей (Node 22): регистрация, вход, хранение прогресса, смена пароля, таблица лидеров. Данные — JSON‑файлы в `/opt/ezeng/data`. Разворачивается отдельным Docker‑контейнером `ezeng-api` на порту 8443 скриптом `server/deploy.sh` (создаёт самоподписанный сертификат на IP сервера, лимиты памяти и CPU, правило ufw); сайт, который уже работает на сервере, не затрагивается.

Приложение ходит на сервер только через главный процесс Electron (`electron/main.cjs`) и доверяет единственному сертификату `electron/server-ca.pem` (pinning). При смене сертификата на сервере нужно положить новый `cert.pem` в `electron/server-ca.pem` и выпустить релиз. Адрес можно переопределить переменными `EZENG_API_HOST` и `EZENG_API_PORT` (для локального тестирования).

### Релиз

Push тега `v*` запускает GitHub Actions (`.github/workflows/release.yml`): собирается установщик для Windows и публикуется в Releases.

```bash
git tag v1.0.1
git push origin v1.0.1
```
